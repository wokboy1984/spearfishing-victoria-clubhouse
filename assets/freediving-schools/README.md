# Victoria Freediving Directory Logos

This folder contains logo assets for `clubhouse-site/data/victoria-freediving-directory.csv`.

Most files are official public assets from the organisation's own website. Where a reliable official logo file was not available during research, the file is a neutral SVG wordmark fallback and the CSV `logo_source_url` is left blank.

Recommended website usage:

- Treat logos as trademarks owned by the listed organisations.
- Prefer showing each logo beside the organisation name, website link, and review/source details.
- Re-check permission before using these marks in sponsor-style placements or paid promotions.
- Use the CSV `due_diligence_note` field in admin/review workflows before publishing endorsements.
